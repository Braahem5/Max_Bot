# MAX Messenger Echo Bot

Простой Эхо-бот для мессенджера MAX, написанный на Python с использованием библиотеки `maxapi`. Бот автоматически зеркально отвечает пользователю на любые текстовые сообщения, а также пересылает обратно медиафайлы (фото, аудио, видео, документы).

## Требования к окружению
* **Python 3.10** или выше
* Установленный менеджер пакетов **Chocolatey** (для развертывания локального туннеля)

---

## Пошаговая инструкция по установке и запуску

### 1. Клонирование репозитория и настройка окружения
Откройте терминал, склонируйте проект и перейдите в рабочую директорию:
```bash
git clone <URL_ТВОЕГО_РЕПОЗИТОРИЯ>
cd Bot
```

Создайте и активируйте виртуальное окружение Python, затем установите необходимые зависимости:
```bash
# Создание окружения
python -m venv venv

# Активация (Windows PowerShell)
.\venv\Scripts\Activate.ps1

# Установка библиотек
pip install python-dotenv maxapi-python[webhook] aiohttp
```

### 2. Настройка локального туннеля (xTunnel)
Поскольку MAX использует вебхуки, вашему локальному серверу нужен публичный HTTPS-адрес. В проекте используется утилита `xtunnel.ru`.

1. Откройте командную строку **от имени Администратора** и установите клиент:
   ```cmd
   choco source add -n=xtunnel -s="https://myget.org"
   choco install xtunnel -y
   ```
2. Перезапустите ваш терминал (или выполните команду `refreshenv`), чтобы обновились системные пути.
3. Зарегистрируйте бесплатный ключ (активируется через команду):
   ```bash
   xtunnel register FREE_KEY
   ```
4. Запустите туннель на порту `8081` (этот порт прописан в коде бота):
   ```bash
   xtunnel http 8081 --tunnel-host tunnel4.com
   ```
   *Оставьте это окно терминала открытым. Скопируйте сгенерированный URL-адрес из консоли (он будет выглядеть как `https://tunnel4.com`).*

### 3. Конфигурация проекта (.env)
Создайте в корневой директории проекта (рядом с `echo_bot.py`) файл конфигурации с именем `.env` и добавьте туда полученный адрес туннеля:

```env
WEBHOOK_URL=https://tunnel4.com
```

### 4. Добавление Токена Бота
Убедитесь, что токен вашего бота прописан внутри инициализации класса в коде `echo_bot.py` или добавлен в переменные среды:
```python
bot = Bot(token="ТВОЙ_ТОКЕН_БОТА")
```

### 5. Запуск
Откройте **второе** окно терминала (не закрывая запущенный туннель), активируйте виртуальное окружение `venv` и запустите скрипт:
```bash
python echo_bot.py
```

После успешного запуска бот очистит старые вебхуки, зарегистрирует новый адрес на серверах MAX и начнет принимать сообщения. Вы можете открыть мессенджер MAX, найти своего бота и протестировать отправку текста или медиавложений.
